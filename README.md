## Embed

Every tool can be embedded on other websites via iframe. Embeds are ad-free.

```html
<iframe src="https://toolstand.io/tools/qr-code/embed" width="100%" height="400" frameborder="0"></iframe>
```

## Tech

- **Static HTML/CSS/JS** — no frameworks, no build step, all client-side
- **Cloudflare Pages** — global CDN, auto-deploy, free
- **PWA** — Service Worker v11, network-first for HTML, stale-while-revalidate for assets
- **Chart.js** — used in Compound Interest, Dividend, DCA, and Keto calculators
- **AdSense** — unobtrusive banner ads (no pop-ups, no video, no embeds)

## Development

```bash
git clone git@github.com:savkliyildiz/toolstand.git
cd toolstand
# Open any .html file in your browser — no build step needed
```

Deploy: push to `main` branch → Cloudflare Pages auto-deploys.
