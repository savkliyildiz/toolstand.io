## Tech Stack

- **Hosting:** Cloudflare Pages (free tier, global CDN, 300+ cities)
- **Domain:** Cloudflare Registrar
- **Frontend:** HTML + CSS + vanilla JavaScript — no frameworks, no build step
- **All Client-Side:** Tools run entirely in the browser, no backend servers
- **CSP:** Strict Content Security Policy
- **Service Worker:** PWA support with offline caching

## Nightly Quality Audit

Every night at 01:00 UTC, an automated 13-check audit scans all tools for:
- JavaScript syntax errors (`.js` files + inline `<script>` blocks)
- HTML integrity (tag balance, structure, accessibility)
- URL accessibility (HTTP 200 on all tool and embed pages)
- Sitemap freshness and coverage
- Service Worker health
- Google Search Console indexing status
- Functional tests (interactive elements, output areas)
- Visual integrity (CSS, viewport, analytics)
- Embed page standards (title, JSON-LD, backlink, analytics.js)
- Live analytics error patterns from Cloudflare KV
- Auto-fix for common issues, auto-commit and deploy
