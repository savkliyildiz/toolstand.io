How to Use the QR Code Generator & Scanner

1. Choose your mode. Select "Generate" to create a QR code from text or a URL, or "Scan" to read an existing QR code using your device camera.

2. Enter your data. In Generate mode, type any text, URL, or data into the input field. The QR code updates in real time as you type. You can encode up to 2,000 characters.

3. Download or print. Click "Download PNG" to save the QR code as an image file, or "Print" to print it directly. The generated code uses error correction level M, so it remains scannable even with minor damage.

4. Scan with your camera. Switch to Scan mode, grant camera permission, and point your camera at any QR code. The decoded content appears instantly — clickable if it's a URL.
