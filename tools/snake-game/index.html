How to Play Snake Game

  1. Start the game — Click the Start button or press any arrow key to begin.
  2. Control the snake — Use arrow keys (←↑→↓) or WASD. On mobile, use the on-screen D-pad or swipe on the game canvas.
  3. Eat the red apples — Each apple increases your score by 10 points and makes the snake longer. The game speeds up as you grow.
  4. Avoid the walls and yourself — Crashing into walls or your own tail ends the game. Your best score is saved automatically.
