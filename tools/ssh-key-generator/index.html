How to Use the SSH Key Generator

  1. Choose your key type — Select RSA 2048-bit, RSA 4096-bit, ECDSA P-256, or ECDSA P-384 from the dropdown.
  2. Click Generate — Your key pair is created instantly using the browser's Web Crypto API. Nothing is sent to any server.
  3. Copy your public key — Use this to add to your server's ~/.ssh/authorized_keys or paste into GitHub/GitLab SSH settings.
  4. Save your private key securely — Copy and save it as a .pem file. Never share your private key with anyone.
